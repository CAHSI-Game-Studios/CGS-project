= Programming Tasks

== Tasks

* Generate notes (`code`)
* Click on notes (`code`)
* Enemy clicks on notes (`code`)
* Choose clown (difficulty choice) (`code`)
* Switch from choosing clown to rhythm game and back
* Handle winning and losing the game
* Implement assets

== Extra Information

* Notes will probably be `Area2D` nodes.
* Generate notes based on:
** BPM — how fast the notes move
** Difficulty — how many notes appear per beat
* Try to keep the game limited to one scene. Notes can be their own scene.
